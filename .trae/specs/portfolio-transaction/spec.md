# 持仓管理与交易记录管理 - 产品需求文档

## 概述
- **摘要**：实现持仓股票与观察列表的整合展示，以及交易记录管理功能，通过FastAPI框架构建符合RESTful规范的API接口。
- **目的**：为用户提供完整的投资组合管理功能，包括自选股管理和交易记录管理，实现数据的自动计算和同步。
- **目标用户**：个人投资者、投资分析师、金融从业者。

## 目标
- 实现自选股的完整CRUD功能
- 实现交易记录的完整CRUD功能
- 自动计算并更新持仓数据（持仓均价、持有数量、市值总计）
- 提供符合RESTful规范的API接口
- 确保数据一致性和事务处理

## 非目标（范围外）
- 不实现用户认证和授权功能
- 不实现实时市场数据更新
- 不实现复杂的投资策略分析
- 不实现交易执行功能

## 背景与上下文
- 项目基于FastAPI框架构建，是OpenBB平台的一部分
- 使用SQLite数据库存储数据，采用WAL模式优化并发访问
- 与现有数据源（AkShare、YFinance、Tushare）集成，获取股票市场数据
- 符号标准化由mysharelib工具处理

## 功能需求
- **FR-1**：自选股管理 - 支持获取全部自选股列表、按股票代码查询单个自选股详情
- **FR-2**：自选股管理 - 支持添加新的自选股到观察列表
- **FR-3**：自选股管理 - 支持更新自选股的策略建议及其他可编辑字段
- **FR-4**：自选股管理 - 支持从自选股列表中移除股票
- **FR-5**：交易记录管理 - 支持获取全部交易记录、按股票代码查询特定股票交易记录、按日期范围查询交易记录
- **FR-6**：交易记录管理 - 支持添加新的交易记录，并触发持仓数据更新
- **FR-7**：交易记录管理 - 支持修改交易记录，并重新计算持仓数据
- **FR-8**：交易记录管理 - 支持删除交易记录，并重新计算持仓数据
- **FR-9**：数据计算 - 自动计算持仓均价（加权平均法）、持有数量、市值总计
- **FR-10**：数据同步 - 交易记录操作后实时更新对应自选股的持仓数据
- **FR-11**：数据验证 - 所有字段需进行类型验证和业务规则验证
- **FR-12**：事务处理 - 确保交易记录操作与持仓数据更新的原子性
- **FR-13**：数据一致性 - 提供数据校验接口，可验证持仓数据与交易记录的一致性

## 非功能需求
- **NFR-1**：API响应时间 - 95%的API请求响应时间不超过200ms
- **NFR-2**：数据一致性 - 交易记录操作与持仓数据更新必须保持一致
- **NFR-3**：错误处理 - 提供清晰的错误信息和适当的HTTP状态码
- **NFR-4**：数据验证 - 所有输入数据必须经过严格的类型和业务规则验证
- **NFR-5**：文档 - 提供完整的API文档（OpenAPI规范）

## 约束
- **技术**：
  - Python 3.11+
  - FastAPI框架
  - SQLite数据库
  - 遵循src-layout项目结构
- **业务**：
  - 卖出交易数量不能超过当前持有数量
  - 交易价格和数量必须大于0
- **依赖**：
  - openbb>=4.7.0
  - mysharelib>=1.0.4

## 假设
- 股票代码格式遵循现有规范（如000001.SZ）
- 市场数据由外部数据源提供，本模块只负责管理用户数据
- 系统运行环境具备足够的资源处理预期的交易量

## 验收标准

### AC-1：自选股管理 - 查询功能
- **给定**：系统中存在自选股数据
- **当**：调用GET /api/v1/portfolio/stocks接口
- **则**：返回所有自选股列表，包含完整的字段信息
- **验证**：`programmatic`

### AC-2：自选股管理 - 单个查询功能
- **给定**：系统中存在特定股票代码的自选股
- **当**：调用GET /api/v1/portfolio/stocks/{symbol}接口
- **则**：返回指定股票的详细信息
- **验证**：`programmatic`

### AC-3：自选股管理 - 创建功能
- **给定**：提供有效的股票代码和相关信息
- **当**：调用POST /api/v1/portfolio/stocks接口
- **则**：成功创建新的自选股，并返回创建结果
- **验证**：`programmatic`

### AC-4：自选股管理 - 更新功能
- **给定**：系统中存在特定股票代码的自选股
- **当**：调用PUT /api/v1/portfolio/stocks/{symbol}接口
- **则**：成功更新自选股信息，并返回更新结果
- **验证**：`programmatic`

### AC-5：自选股管理 - 删除功能
- **给定**：系统中存在特定股票代码的自选股
- **当**：调用DELETE /api/v1/portfolio/stocks/{symbol}接口
- **则**：成功删除自选股，并返回删除结果
- **验证**：`programmatic`

### AC-6：交易记录管理 - 查询功能
- **给定**：系统中存在交易记录数据
- **当**：调用GET /api/v1/portfolio/transactions接口
- **则**：返回所有交易记录列表，包含完整的字段信息
- **验证**：`programmatic`

### AC-7：交易记录管理 - 按股票查询功能
- **给定**：系统中存在特定股票的交易记录
- **当**：调用GET /api/v1/portfolio/transactions?symbol={symbol}接口
- **则**：返回指定股票的交易记录列表
- **验证**：`programmatic`

### AC-8：交易记录管理 - 按日期范围查询功能
- **给定**：系统中存在特定日期范围内的交易记录
- **当**：调用GET /api/v1/portfolio/transactions?start_date={start}&end_date={end}接口
- **则**：返回指定日期范围内的交易记录列表
- **验证**：`programmatic`

### AC-9：交易记录管理 - 创建功能
- **给定**：提供有效的交易记录信息
- **当**：调用POST /api/v1/portfolio/transactions接口
- **则**：成功创建新的交易记录，并自动更新对应自选股的持仓数据
- **验证**：`programmatic`

### AC-10：交易记录管理 - 更新功能
- **给定**：系统中存在特定的交易记录
- **当**：调用PUT /api/v1/portfolio/transactions/{id}接口
- **则**：成功更新交易记录，并重新计算对应自选股的持仓数据
- **验证**：`programmatic`

### AC-11：交易记录管理 - 删除功能
- **给定**：系统中存在特定的交易记录
- **当**：调用DELETE /api/v1/portfolio/transactions/{id}接口
- **则**：成功删除交易记录，并重新计算对应自选股的持仓数据
- **验证**：`programmatic`

### AC-12：数据计算 - 买入交易
- **给定**：用户执行买入交易
- **当**：创建买入交易记录
- **则**：系统增加持有数量，使用加权平均法重新计算持仓均价
- **验证**：`programmatic`

### AC-13：数据计算 - 卖出交易
- **给定**：用户执行卖出交易
- **当**：创建卖出交易记录
- **则**：系统减少持有数量，重新计算持仓均价，确保卖出数量不超过当前持有数量
- **验证**：`programmatic`

### AC-14：数据一致性 - 事务处理
- **给定**：执行交易记录操作
- **当**：创建/更新/删除交易记录
- **则**：系统确保交易记录操作与持仓数据更新的原子性，防止数据不一致
- **验证**：`programmatic`

### AC-15：数据一致性 - 校验接口
- **给定**：系统中存在交易记录和持仓数据
- **当**：调用GET /api/v1/portfolio/validate接口
- **则**：返回持仓数据与交易记录的一致性验证结果
- **验证**：`programmatic`

### AC-16：无持仓时的展示
- **给定**：用户无持仓股票
- **当**：查询自选股列表
- **则**：持仓均价、持有数量及市值总计字段显示为零值
- **验证**：`programmatic`
